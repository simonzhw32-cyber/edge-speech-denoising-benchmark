# GTCRN / LiSenNet 参数量与速度说明

## 当前实验记录

| 项目 | GTCRN | LiSenNet |
|---|---:|---:|
| 总参数量 | 48,245 | 36,783 |
| 可训练参数量 | 23,669 | 36,783 |
| 测试推理 RTF | 0.001884925 | 0.001767802 |

LiSenNet 总参数少约 24%；此次独立测量的推理耗时低约 6.2%。
两者固定测试集上的降噪效果接近。

这些测量不是同一次环境中的并排测试，不能据此确定稳定的速度优势，
也不能推断端侧设备上的速度。训练速度尚未完成定量比较。

## 论文与官方实现说明

GTCRN 原论文报告约 23.7K 参数；官方实现将不可训练的 ERB
频带映射计入后，更新为约 48.2K 参数。因此必须同时报告总参数
与可训练参数，避免把统计口径差异当作网络学习规模差异。

LiSenNet 通过频率下采样、小型时间/频率双路径循环网络等设计降低
计算开销。论文还提供可选噪声检测器，但当前速度结果不能归因于
该模块，除非确认实验实际启用了它。

LiSenNet 论文报告约 56M MAC/s；GTCRN 官方更新值约 33M MAC/s。
以上是作者报告值，不是本仓库重新测得的运算量。
参数量、运算量和实际耗时是不同指标；本次速度差异的具体原因
仍需相同环境中的并排计时与性能分析。
